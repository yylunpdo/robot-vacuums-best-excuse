# The Robot Vacuum's Best Excuse

Entry for the [make.fun](https://make.fun) bounty
**[The Robot Vacuum's Best Excuse](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214)**:
write one line, at most 140 characters, giving the funniest excuse a
robot vacuum could offer for missing a spot.

`main.py` (pure Python stdlib, no dependencies) writes the entry to
`/output/entry.txt`:

> I didn't miss that spot - the dust bunny living there pays rent, and I don't evict tenants mid-lease. I respect the lease.

## Run

```sh
python3 main.py
```
